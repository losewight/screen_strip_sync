# Git / GitHub：禁止 Agent 标签与署名

公开仓库的提交说明与作者信息里**严禁**出现任何 AI Agent 标签或署名身份，包括但不限于：

- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- `Co-authored-by: ... <...agent...>` / `Co-authored-by: Antigravity <...>` 等任何 AI 助手署名
- 任意含 `cursoragent`、`agent` 标签、AI 标识或 bot trailer 的提交正文与 trailer
- 自动化工具生成的徽标（如 `🤖 Generated by ...`）

## 强制手段

克隆后执行一次：

```powershell
.\scripts\setup-git-hooks.ps1
```

详见 [`.githooks/README.md`](../.githooks/README.md)。

## 对 Agent / 贡献者

- 写 `git commit` 消息时**绝不**追加任何 Agent / Cursor / AI 的 `Co-authored-by` 或签名标签。
- 不要用 `git commit --no-verify` 绕过上述拦截。
- 若历史里出现了 Agent 标签，用 `git-filter-repo --replace-message` 清掉后再 force-push（需仓库维护者明确授权）。
