# 1.1.0

相对 v1.0.2 以来的更新。

## 新增

- **智能忽略电影黑边**：看片时自动避开上下黑边，灯带不再被黑边带暗；跟色页可开关，默认开启
- **编辑现有矫正框**：映射校准里可直接改已有采样框，不必整轮重新矫正
- **运行中一键停止**：流光溢彩 / 屏幕氛围 / 纯色在运行时可点「停止」（与「关灯」不同，只停当前方案）

## 改进

- **暗场更稳**：暗场景下减少灯带暗闪、突然啪亮、灭不干净
- **渐黑不再跳色**：画面慢慢变黑时，颜色不再飘成奇怪的极光色
- **硬切更跟手**：画面突然亮灭时，灯带响应更快
- **跟色颜色更鲜**：饱和度统一按「减去中性色」处理（界面不再切换算法）
- **跟色默认参数更新**（升级后自动写入一次；串口、矫正框、氛围等其它设置不变）
  - 时间过渡平滑度 0.00、模糊 0、饱和度 100%、暗部过滤 30、智能忽略电影黑边开

## 修复

- 修复关灯或切到黑场时，开启墙面补偿可能闪一下亮色的问题

## 鸣谢

本版本部分思路参考了开源项目 [HyperHDR](https://github.com/awawa-dev/HyperHDR)（电影黑边检测、暗场抗闪等），在此致谢。本软件为独立实现，与 HyperHDR 无隶属关系。

## 安装

- **安装包**：运行 `ScreenStripSync-1.1.0-windows-x64-Setup.exe`
- **绿色版**：解压后运行 `helper.exe`（托盘常驻；界面可随时开关）
- **系统要求**：仅支持 Windows 10/11 x64
