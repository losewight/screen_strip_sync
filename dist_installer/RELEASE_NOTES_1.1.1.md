# 1.1.1

相对 v1.1.0 以来的更新。

## 新增

- **HDR 桌面跟色**：支持 HDR（FP16 scRGB）抓屏并 tone-map 到灯带可用的 sRGB，高光不再发灰发白
- **智能忽略字幕**：自动避开内容区底部字幕带，减少白字/半透明条染灯；跟色页可开关，默认开启

## 改进

- **变暗更干脆**：开启时间过渡平滑时，亮起更柔、变暗更快跟上画面（非对称平滑）
- **电影黑边更稳**：忽略单侧/不对称黑边帧，减少误锁黑边或错误回到全屏采样
- **安装/卸载更安全**：检测到程序在运行时先确认，再通过 IPC 正常退出，不再强杀进程

## 修复

- 开启「智能忽略字幕」后，个别取色框被裁得过扁时会重新展开，避免采样异常

## 安装

- **安装包**：运行 `ScreenStripSync-1.1.1-windows-x64-Setup.exe`
- **绿色版**：解压后运行 `helper.exe`（托盘常驻；界面可随时开关）
- **系统要求**：仅支持 Windows 10/11 x64
